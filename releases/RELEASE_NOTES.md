# Rokto Dorkar v1.0.0

The first Android release of the Rokto Dorkar blood donor network.

## Included

- Email-first registration with Brevo OTP verification
- Secure email OTP password recovery
- Donor search by blood group and Bangladesh administrative location
- Donor eligibility, availability, phone contact, and last-donation details
- Urgent blood requests with fulfillment status
- User, moderator, and admin roles
- Manual donor entry and phone-based duplicate review
- Gender-based fallback avatars without profile-photo storage
- Live connection to the Render-hosted Django API and Neon PostgreSQL database

## Android requirements

- Android 7.0 (API 24) or newer
- Internet connection for live donor and request data

## Integrity

Verify the APK with the accompanying `SHA256SUMS.txt` file.

This APK is development-key signed for direct installation and evaluation. A private release key is required for Google Play distribution.
